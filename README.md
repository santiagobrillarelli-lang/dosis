# Dosis

App para llevar el stock de medicamentos, armar el pastillero y saber qué pedir en la próxima consulta.

Es una app web instalable (PWA): se abre en Chrome en Android y se instala con "Instalar app".
Los datos se guardan solo en el teléfono (localStorage). Si se desinstala la app o se borran los datos de Chrome, los datos se pierden.
